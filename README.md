# iLivePDF

Calm, guided PDF workflows — merge, split, compress, convert, protect, and more.

**GitHub:** https://github.com/Thefallenxjedi/Ilivepdf

## Use this project

### 1. Open the repo
https://github.com/Thefallenxjedi/Ilivepdf

### 2. Run it on your machine

```bash
git clone https://github.com/Thefallenxjedi/Ilivepdf.git
cd Ilivepdf
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

### 3. Optional: use it in GitHub Codespaces
On the repo page, click **Code → Codespaces → Create codespace on main**, then run:

```bash
npm install
npm run dev
```

Codespaces will give you a browser link to use the app.

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm start` — run production build
- `npm run lint` — lint
